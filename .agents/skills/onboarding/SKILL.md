# Onboarding Workflow

Wenn der User diesen Skill aufruft, lies bitte die folgenden Dateien um eine grundlegende Ahnung der Struktur des Spiels zu bekommen:
- [AGENTS.md](file:///d:/game-dev/homasim-godot/.agents/AGENTS.md)
- [alpha_backlog.md](file:///d:/game-dev/homasim-godot/wiki/alpha_backlog.md)
- [status_quo.md](file:///d:/game-dev/homasim-godot/wiki/status_quo.md)
- [uebergabe.md](file:///d:/game-dev/homasim-godot/_work/uebergabe.md) (falls vorhanden, für den nahtlosen Anschluss an die letzte Session)
- [alpha_grid_rework_plan.md](file:///d:/game-dev/homasim-godot/wiki/alpha_grid_rework_plan.md) (**verbindlicher Plan für den Alpha-Start / Nav-Rework – vollständig lesen, nichts davon eigenmächtig ändern, Phasen nur nach Go von Peter**)
- Prüfe außerdem mit `git branch --show-current`, auf welchem Branch du bist (`dev` = Alpha v0.3.x, `prealpha` = v0.2.x, `master` = alt/nicht verwenden).

Dann hole dir aus der [version.txt](file:///d:/game-dev/homasim-godot/version.txt) die aktuelle Version und lies die dazu passende Changelog-Datei aus dem Verzeichnis [changelog](file:///d:/game-dev/homasim-godot/changelog/).

Erstelle eine kurze Zusammenfassung und warte dann auf weitere Infos.
